# reference/ 参考資料

ルーブリックと知見カードの「元資料」を置く場所。ここのファイルは編集せず、原本のまま置く。

| ディレクトリ | 置くもの |
|---|---|
| koubo/    | 公募要領（種目別・年度別。例: koubo/2027/kiban-c.pdf） |
| yoshiki/  | 様式（Word/PDF。例: yoshiki/2027/kiban-c_S-13.docx） |
| shinsa/   | 審査の手引き、評定基準、審査区分表、審査委員向け資料 |
| seminar/  | 科研費セミナー等の資料・メモ |

## 各資料に付けるメタ情報

ファイルを置いたら同じディレクトリの `index.md` に一行追加する。

```
| ファイル | 種目 | 年度 | 出典 | 共有可否 | 備考 |
```

- 出典: JSPS / 文科省 / 学内 / 外部セミナー名 など
- 共有可否: 公開（JSPS等の公開資料）/ 学内限定 / 個人メモ
  → 他機関に配布する知見DBに入れてよいかの判断に使う
同名の .txt は pypdf で抽出した全文（機械可読用）。
