## 欄1「研究目的、研究方法など」

Wordの段落見出し: `１　研究目的、研究方法など` → `（概要）` → `（本文）`

- 概要: 冒頭に簡潔に（記入要領では10行程度）
- 本文の小項目（様式の指示書きより）
  1. 本研究の学術的背景や本研究の着想に至った経緯、研究課題の核心をなす学術的「問い」
  2. 本研究の目的および学術的独自性と創造性
  3. 関連分野（若手: 関連する国内外）の研究動向と本研究の位置づけ
  4. 本研究で何をどのように、どこまで明らかにしようとするのか
  5. 本研究の目的を達成するための準備状況
  6. 本研究がどのような国際性を有するか（基盤B・Cのみ）
  - 研究分担者がいる場合は代表者・分担者の具体的な役割（基盤B・Cのみ）

### 小項目 → 評定要素の対応

| 小項目 | 評定要素 | 規程の問い |
|---|---|---|
| (1) 背景・経緯・学術的「問い」 | A(1) 学術的重要性 | 核心をなす学術的「問い」は明確か。着想に至る経緯は明確か |
| (2) 目的・独自性・創造性 | A(1) 学術的重要性 | 学術的独自性や創造性が認められるか。推進すべき重要な課題か |
| (3) 研究動向と位置づけ | A(1) 学術的重要性 | 関連する国内外の研究動向と研究の位置づけは明確か |
| (1)〜(4) 全体 | A(1) 学術的重要性 | より広い学術、科学技術、社会への波及効果が期待できるか |
| (4) 何を・どのように・どこまで | A(2) 研究方法の妥当性 | 研究方法等は具体的かつ適切か。研究経費は計画と整合しているか（Web入力項目「研究経費とその必要性」と突合） |
| (5) 準備状況 | A(2) 研究方法の妥当性 | 目的達成のための準備状況は適切か |
| (6) 国際性 | B 国際性 | 世界をけん引 / 協同で世界の発展に貢献 / 我が国独自の高い価値、のいずれかを発揮できるか |

## 欄2「応募者の研究遂行能力及び研究環境」（2頁以内）

- (1) これまでの研究活動（主要な研究業績を含む）: 本計画の実行可能性を示す関連活動を中心に。網羅ではなく主要業績。業績は同定に十分な書誌情報。論文は掲載済みまたは掲載確定のみ。国際的取組、研究中断期間の説明も可
- (2) 研究環境（施設・設備・資料等）
- 分担者がいる場合は想定される役割に関連した活動（基盤B・C）

| 小項目 | 評定要素 | 規程の問い |
|---|---|---|
| (1) これまでの研究活動 | A(3) 遂行能力・環境 | これまでの研究活動等から見て十分な遂行能力を有するか |
| (2) 研究環境 | A(3) 遂行能力・環境 | 必要な施設・設備・資料等、研究環境は整っているか |

## 欄3「人権の保護及び法令等の遵守への対応」（1頁以内）

- 総合評点には考慮しない（規程 別添5・6 留意事項）。該当しない場合はその旨を記述。
- レビューでは「記述漏れ」「該当なしの明記漏れ」のチェックのみ。

## 欄4「研究計画最終年度前年度応募を行う場合の記述事項」（基盤B・Cのみ、1頁以内）

- 当初研究計画及び研究成果 / 前年度応募する理由（各10行程度）。該当しなければ空欄のまま。

## Web入力項目（添付ファイル外、レビューで参照するもの）

- 研究課題名
- 研究経費とその必要性（設備備品費、消耗品費、旅費、人件費・謝金、その他の明細）→ A(2) 経費の整合性
- 学術的「問い」（公開用）→ 欄1(1) の「問い」と一致しているか
- 研究組織（若手を除く）→ 欄1 の役割記述と整合しているか

## 審査の仕組みでレビューに効く点

- 評定要素A(1)〜(3)は4段階の絶対評価。2以下を付けた審査委員は「どの項目が不十分か」を選ぶ → 上表の「規程の問い」がそのまま減点理由の単位になる。
- 総合評点は相対評価（目安 4:10%, 3:20%, 2:40%, 1:30%）。全要素で高評価である必要はない。
- 1段階目で審査委員は「長所と短所を中心とした審査意見」を必ず書く → レビューの出力形式もこれに合わせる。
- 不採択者には各評定要素の素点（平均）と定型所見が開示される → 研究者が持つ過去の開示結果は知見DBの材料。
- 審査委員は研究計画調書を生成AIに入力してはならない（審査側の制約。応募側には適用されない）。

## 評定要素B「国際性」の扱い（2026-09-23 確認）

出典: 公募要領 p.17（PDF p.19）、審査規程 第2章 配分額の調整 c / (ォ)（PDF p.9-10）、別添5（PDF p.54-56）、審査の基本的考え方（PDF p.3-4）

- **総合評点（採否を決める評点）はA(1)〜(3)のみで付ける。** 別添5の総合評点の指示は「Ａ．（１）～（３）の評定要素に着目しつつ」で、Bは含まれない。Bは「さらに」別途4段階の絶対評価を行う扱い。
- Bの用途は次の二つ（公募要領・規程で明記）:
  1. **配分額**: 国際性の評価が高い研究課題について応募額を尊重して配分額を決定する（充足率を上げる方向の調整）。基盤A・B・Cが対象。
  2. **追加採択**: 基盤B・Cにおいて、若手研究者による国際性の評価が高い研究課題を追加的に採択する「国際・若手支援強化枠」。規程では「国際性の評価が高い若手研究者等に対する研究助成の充実を図るための調整」。
- 若手研究にはBがない（様式にも(6)がない）。
- 令和7年度公募から導入。令和6年度公募版の評定基準PDF（reference/shinsa/2024）にも既に記載あり。

### レビューへの含意

- 国際性の記述の弱さは、通常の採否ラインには直接効かない。ただし (a) 採択された場合の配分額、(b) 若手研究者が基盤B・Cに応募する場合の追加採択枠、に効く。
- レポートでは「採否に効く観点（A）」と「配分額・追加採択枠に効く観点（B）」を分けて示す。若手研究者が基盤Cに応募するプロジェクトでは、Bの重要度を上げる。
- 開示情報で国際性の点数が採択平均を下回っていても、不採択の主因とは限らない。再挑戦モードの重点付けではAの＊項目を優先し、Bは配分額・強化枠の観点として別枠で扱う。
- 「若手研究者」の定義（年齢・学位取得後年数）と強化枠の件数は公募要領本文に明記されていないため、必要なら文科省の第12期研究費部会の資料で確認する。

## 審査の手引（令和8年度、審査委員向け）から分かる審査の実態（2026-09-23 追記）

出典: reference/shinsa/2026/r08_tebiki04_kibanbcwakate.pdf

- **審査意見は200字程度（最大300字）**。長所と短所を中心に、他の審査委員に伝わるように書く。応募者には開示されない（開示されるのは評定要素の素点と＊項目のみ）。2段階目は他の委員の審査意見を見て評点を付け直す。
  → レビューエンジンに「審査委員が書くであろう200字の審査意見（長所・短所）」を模擬生成させると、研究者が受け取る審査の像に近い。
- **評点分布はシステムで強制**される（4:10% / 3:20% / 2:40% / 1:30%。分布が一致しないと審査を終了できない）。「3にしたいが件数制限で2にした」場合は審査意見に書くよう指示。
  → 総合評点は純粋な相対評価。絶対評価の評定要素（開示される点数）と総合評点は別物。
- **2段階目の対象はボーダーゾーンの課題**: 各小区分の採択予定件数の上位80%〜120%にあたる課題、それより上位で1名でも総合評点1を付けた課題、それより下位で1名のみ総合評点1を付けたがその1名を除くとボーダー以上になる課題。
  → 採択予定件数の80%以内に入れば1段階目で実質確定。ボーダーに入ると他の委員の審査意見（長所・短所）が採否を左右する。
- **国際性の評価は「各分野で定義が異なる」ため、3類型に限らず当該審査区分の特性に応じて評価**するよう指示。
  → R18 の水準記述で3類型への当てはめを必須にしない。
- **研究計画調書に記載のない情報のみに基づいて評価しない**。確認のため他の情報（researchmap等）を参照するのは可。
  → 業績や準備状況は「調書に書いてあること」がすべて。書き漏れは存在しないのと同じ。
- **審査区分の選択が不適切でも、それだけを理由に評価を下げてはいけない**。
  → R19 は「減点される」ではなく「専門外の委員に読まれる」リスクとして扱う。
- **重複応募を理由に低評価にしない**。
- 研究経費の妥当性は計画に照らして判断。設備・人件費・バイアウト経費の計上の有無だけで判断しない。
- 令和7年度の新規採択の平均充足率: 基盤B 72.3%、基盤C 71.3%、若手 73.8%。
  → 応募額の7割前後が配分される前提で計画の現実性を考える材料。国際性が高い課題は応募額を尊重した配分。
- アンコンシャス・バイアスの排除が明記されている。
