# rubric/ — KAKEN Polaris のルーブリック

`rubric_v0.yaml` が正本。レビューエンジンはこれを読み、観点ごとに「引用・水準・理由・方向・問いかけ・面談ギャップ」を出す。

## 構造

- **evaluation_elements**: 審査規程の評定要素（A1〜A3 は総合評点＝採否に効く。B は配分額・強化枠に効く）
- **observations**: 観点。1件 = 審査委員が「不十分」を選ぶ単位（規程の問い）を様式の小項目に落としたもの。21件
  - `levels` 4/3/2/1: 観察できる状態で書く（抽象語禁止）
  - `evidence`: LLM に引用させる箇所
  - `directions`: 修正の方向（修正文は書かない）
  - `questions`: 研究者本人にしか答えられない問い
  - `transcript_check`: 面談テキストとの突合点
  - `applies_to` / `condition` / `note_wakate`: 種目差分
  - `cards`: この観点にぶら下がる知見カード（今後）
- **output_contract**: レポートの出力形式と並べ方、再挑戦モードの重点付け
